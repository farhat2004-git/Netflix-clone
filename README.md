# 🎬 Netflix Clone

A responsive Netflix-inspired website built using HTML, CSS, and JavaScript.  
This project recreates the look and feel of a streaming platform with a modern UI, movie sections, navigation bar, and responsive design.

## 🚀 Live Demo

Coming soon...

## 📌 Features

- 🎬 Netflix-inspired user interface
- 📱 Responsive design for different screen sizes
- 🧭 Navigation bar
- 🎞️ Movie/show sections
- 🔥 Featured content section
- 🖼️ Movie thumbnails and banners
- 🎨 Modern CSS styling
- ⚡ JavaScript interactions
- 📂 Organized project structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
